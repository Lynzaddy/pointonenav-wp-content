# Elementor Section Naming Convention Guide

## ✅ Recommended Naming Format

```
section-[layout]-[modifier]-[content]
```

---

## 🔤 Breakdown of Terms

| Part       | Description                                                                  |
| ---------- | ---------------------------------------------------------------------------- |
| `section`  | Always prefix with this to indicate it's a full-width reusable section       |
| `layout`   | Describes the structure (e.g., `1col`, `2col`, `3col`, `hero`, `grid`, etc.) |
| `modifier` | Describes spacing, alignment, or variation (e.g., `wide-gap`, `align-left`)  |
| `content`  | Describes the purpose/content (e.g., `cta`, `video`, `form`, `bio`, etc.)    |

---
